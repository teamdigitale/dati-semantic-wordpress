# dati-semantic-wordpress-v3.5

WordPress image for [schema.gov.it](https://www.schema.gov.it): WordPress 6.8.3 on PHP 8.4.27 (Apache). See the header of the [`Dockerfile`](./Dockerfile) for the base recipe and how to update PHP.

The image is published as a **private** package on `ghcr.io/teamdigitale/dati-semantic-wordpress`; pulling it requires a token with `read:packages`.
